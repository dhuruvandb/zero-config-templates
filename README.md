# Zero-Config Templates

Production-ready starter templates with TypeScript, JWT authentication, Prisma ORM, pre-written tests, and **Docker support**.

Each template is a fully configured project generated by [Zero-Config](https://zero-config.vercel.app/) — just select your stack and download.

## What's Included

Every template comes with:

- **JWT Auth** — Access tokens (15m) + Refresh tokens (7d) with rotation
- **Full CRUD** — Create, Read, Update, Delete with ownership verification
- **Prisma ORM** — Type-safe database access
- **bcrypt** — Password hashing (10 rounds) + strong password validation
- **Pre-written Tests** — Auth flow, CRUD, edge cases, and auth guards
- **Environment Variables** — .env configuration
- **CORS** — Pre-configured for frontend-backend communication
- **Dockerfile** — Production-ready multi-stage builds for each template

## 🐳 Docker Support

All 7 templates include production-grade Dockerfiles with multi-stage builds for optimal image size and security.

### Build & Run

```bash
# Build any template (example: React)
cd react
docker build -t my-react-app .

# Run it
docker run -d -p 8080:80 my-react-app
```

### Port Reference

| Template    | Port   | Exposed Service                   | Base Image                              |
| ----------- | ------ | --------------------------------- | --------------------------------------- |
| **React**   | `80`   | nginx (static build)              | `node:22-alpine` → `nginx:alpine`       |
| **Vue.js**  | `80`   | nginx (static build)              | `node:22-alpine` → `nginx:alpine`       |
| **Next.js** | `3000` | Next.js standalone server         | `node:22-alpine` (single stage pattern) |
| **Angular** | `4000` | Angular SSR server (`server.mjs`) | `node:22-alpine` (two-stage)            |
| **Express** | `5000` | Node.js (`dist/index.js`)         | `node:22-alpine` (two-stage + Prisma)   |
| **NestJS**  | `5000` | Node.js (`dist/main.js`)          | `node:22-alpine` (two-stage + Prisma)   |
| **Fastify** | `5000` | Node.js (`dist/index.js`)         | `node:22-alpine` (two-stage + Prisma)   |

> **Note:** Backend templates with Prisma require a database. Set the `DATABASE_URL`
> environment variable when running the container, for example:
>
> ```bash
> docker run -d -p 5000:5000 -e DATABASE_URL="postgresql://user:pass@host:5432/db" my-express-app
> ```

### Docker Features

- ✅ **Multi-stage builds** — Builder stage compiles TypeScript, runner stage is minimal
- ✅ **`npm ci` for reproducibility** — Uses exact dependency versions from lock file
- ✅ **Prisma Client generation** — Generated at build time for the target architecture
- ✅ **Minimal production images** — Dev dependencies never reach the final image
- ✅ **Non-root users** — Follows security best practices (nginx default, node user)
